# Tic-toc-Toe
A simple Tic-Tac-Toe game built using Flutter with the MVVM model, Hive local database, and Provider for state management.
✨ Features:
✅ Play Tic-Tac-Toe with two players
✅ Save game history using Hive database
✅ Follows MVVM (Model-View-ViewModel) architecture
✅ Uses Provider for state management
✅ Smooth UI animations

🛠️ Tech Stack Used:
Flutter (Dart)
Hive (Local storage)
Provider (State Management)
MVVM Architecture
Cupertino & Material Widgets
